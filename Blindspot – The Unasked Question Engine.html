Problem

Teams fail on questions nobody asked. Users: students, founders, PMs and analysts. Success = more critical gaps surfaced before kickoff, each backed by evidence.

Architecture

A single static client app with a pure, testable engine function. Rules are data (regex plus recommendation), so adding one is a one-line change.

Privacy and cost

Zero server, zero upload, zero running cost. Safe for confidential documents.

Adoption and scale

Host anywhere, no install. Next: browser extension, Drive and Notion connectors, a team rule-pack marketplace, and an optional LLM layer.

Validation and honest limits

Live test suite on planted-gap samples, edge cases and a “well-written” control document.

Known limitations

Detection is keyword and pattern based, so it can miss paraphrased coverage and flag topics a document covers in other words. Images are not OCR’d (add a caption). Links are not fetched. Samples are team-authored, so recall numbers are indicative, not a benchmark. The roadmap adds an LLM reasoning layer on top of this deterministic evidence base.
